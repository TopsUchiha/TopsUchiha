## What I build and study

I build practical web applications where the public experience and the operational side both matter: websites, admin dashboards, shipment and order workflows, and database-backed tools. Alongside that work, I am studying web security, Linux, and low-level systems programming.

## Featured work

### [Vantage](https://github.com/TopsUchiha/vantage) · [Live site](https://mate-gray.vercel.app)

A logistics and transport platform built with **Next.js 16, React 19, TypeScript, Tailwind CSS, and PostgreSQL**. It has a public services site plus a private shipment operations dashboard. The dashboard supports creating, searching, filtering, and tracking shipments; status management; customer messages; receipts; route details; package information; maps; and barcode generation.

### [Smokeyz BBQ](https://github.com/TopsUchiha/project-Jenking)

A full e-commerce platform built with **Node.js, Express, SQLite, vanilla JavaScript, Stripe, PayPal, SendGrid, and Vercel**. It includes a product catalogue, cart, checkout, order tracking, payment options, and a JWT-protected admin CMS for orders, customers, inventory, and products. The project documents parameterized queries, validation, rate limiting, CSRF protection, bcrypt password hashing, and security headers.

### [BBQ Smokerz](https://github.com/TopsUchiha/BBQ-website)

A second generation BBQ storefront and admin system built with **Next.js 14, TypeScript, Tailwind CSS, Prisma, PostgreSQL, and NextAuth**. It covers catalogue management, reviews, customer messages, and site settings.

### [BBQ Smokerz — current build](https://github.com/TopsUchiha/bbq-smokerz)

An updated e-commerce build using **Next.js 14, TypeScript, Tailwind CSS, Prisma, PostgreSQL, and NextAuth**. It adds an admin dashboard for products, categories, orders, reviews, messages, and business settings.

### [Havanese Havens](https://github.com/TopsUchiha/Havanese)

A full-stack adoption and rescue website with a **vanilla HTML/CSS/JavaScript** frontend and an **Express + SQLite** backend. It includes an admin portal, puppy and application management, image uploads, schema migrations, price management, JWT sessions, validation, rate limiting, CSP headers, and deployment notes for Render.
